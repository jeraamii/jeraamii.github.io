Classification · Streamlit app

Credit Score Prediction

Compared five classifiers (Random Forest, Gradient Boosting, Decision Tree, AdaBoost and Logistic Regression) to predict credit score as Good, Standard or Poor, on a lecturer-provided dataset of about 25,000 records.

Random Forest performed best among the five models tested. Because the target classes are imbalanced, I used weighted F1 alongside accuracy to compare performance. Experiments are tracked in MLflow, with a FastAPI inference backend and a Streamlit app for single and batch CSV predictions.

Limitation: These results come from a lecturer-provided dataset and should not be interpreted as evidence that the model is ready for real lending decisions. A real credit-risk assessment would require further validation, class-level error analysis, and checks for fairness and data leakage.

Classification · AWS deployment

Spaceship Titanic Classifier

Compared Logistic Regression, Random Forest and XGBoost. I engineered features from cabin deck, cabin side and total spending, and imputed missing values. XGBoost achieved a Macro F1 of 0.8096 on a held-out test set of 1,739 passengers. I also checked generalization: Random Forest reached about 0.95 training accuracy versus 0.80 test accuracy, indicating a substantial train–test gap.

Deployed end-to-end on AWS: a SageMaker real-time endpoint serving a Streamlit app hosted on Amazon EC2, run as a systemd service and set up with a user-data bootstrap script. Built on AWS Academy; the code and screenshots are in the repository.

Time-series forecasting

LSTM Stock Price Prediction

Compared a baseline LSTM with a stacked, dropout-regularized LSTM to forecast next-day closing prices for AMD and AAPL, using a five-day input window and more than 30 years of daily data.

The most recent year is held out as the test period, and the scaler is fitted on training data only to reduce leakage risk. The baseline LSTM achieved a test MAPE of 2.44% on AMD and 4.78% on AAPL, outperforming the stacked model on both stocks. Prediction lag is a documented limitation, and these results are not evidence of a profitable trading strategy.
